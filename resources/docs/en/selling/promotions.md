A promotion takes money off the price while it is running. The till works it out by itself, so cashiers do not have to remember anything.

## Make one
Open **Sales → Promotions → New promotion**.
1. **Kind**
   - **Percent off**: for example 10% off.
   - **Amount off each unit**: for example 500 off every unit.
   - **Buy X, get Y free**: buy 2, get 1 free. Every full group of 3 units has one free. Works on the same product.
   - **Bulk price**: from a quantity, for example from 12 units, 15% off (or an amount per unit).
2. **Applies to**: every product, some categories, or some products.
3. **When** (all optional): first and last day, days of the week, and a time window for a happy hour. A window can pass midnight (22:00 to 02:00). Times use the shop clock.
4. **Coupon** (optional): give it a **code** and it only works when the cashier types that code. You can limit how many sales may use it.

## At the till
Running promotions show on the basket line (the promotion's name and what it takes off) and in the **Promotions** row of the totals. To use a coupon, type its code under the basket and press **Apply**. The cashier's own **Discount** is taken off what is left after the promotion.

## Rules to know
- Each line gets **one** promotion, the one that takes the most off. Promotions are never added together.
- A coupon that does not beat an automatic promotion on any line gives nothing and is not counted as used.
- Turning a promotion off, or letting it end, never changes sales already made. Past sales keep the promotion's name.
- A sale made offline uses the promotions that were running when it was made. Coupons need internet.
- The price on the receipt already includes the promotion; the sale shows the promotion total.
